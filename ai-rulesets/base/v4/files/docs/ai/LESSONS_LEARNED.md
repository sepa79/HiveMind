# Lessons Learned

Prefer storing lessons in HiveMind.

Use this file only:
- when HiveMind is unavailable,
- for portable repository-level lessons,
- for recurring production/project failure patterns that should travel with the repo.

Keep entries short and actionable.

## Template

```text
Date: YYYY-MM-DD
Area: TODO
Lesson: TODO
Trigger: TODO
Rule/Action: TODO
```

---

If you change this tracked standard file, refresh the canonical HiveMind marker for the project with `project_standard_marker_update` or `npm run hivemind:standard -- marker update --project <project-id> --target <repo>`.
